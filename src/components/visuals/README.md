# Interactive Visuals

This directory houses interactive visual learning components for the SOC Analyst L1 platform.

## Visual Categories
- **Network Topologies**: Interactive diagrams showing corporate networks, DMZs, firewalls, and tap points.
- **Log Flow Architectures**: Visual representations of syslog, agent forwards, SIEM log collectors, and parsers.
- **Process Trees**: Interactive parent-child Windows / Linux process hierarchy diagrams (Sysmon Event ID 1).
- **Incident Timelines**: Sequential timeline cards visualizing attack progression across the MITRE ATT&CK lifecycle.
- **Packet Inspections**: Interactive protocol decoders showing TCP/IP headers, DNS queries, and TLS handshakes.
