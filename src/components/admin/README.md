# Admin Components

This directory contains administrative components for managing the platform.

## Features
- **User Management**: Inspect student accounts, assign roles (STUDENT, INSTRUCTOR, ADMIN), view XP and streak statistics.
- **Module & Unit Editor**: Configure learning objectives, prerequisites, published/locked states, and content payloads.
- **Analytics & Metrics**: Cohort completion rates, topic failure rates, scenario decision paths, and engagement graphs.
